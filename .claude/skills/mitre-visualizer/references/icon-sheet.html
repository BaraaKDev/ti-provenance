Two marks that carry meaning

These repeat deliberately across the set. Keep them consistent when adding an icon — a slash used decoratively would break the reading of every icon that uses it properly.

A diagonal slash negates the capability

Stealth, Defense Impairment, ICS Evasion and Inhibit Response Function. Nothing else.

An X inside an object destroys that object

The container says what was destroyed: a database for Enterprise, a plant for ICS.

Colour is not part of the icon. Every path uses stroke="currentColor", so the chip inherits its phase colour — steel for access phases, warming through escalation, to ember at the objective. Never hard-code a hex value in a path.
