The Intrusion

Selective targeting, then quiet collection

Eight ATT&CK tactics in sequence. This is a narrower mapping than Agrius or Akira, and the shape is the point: Andariel spends its effort at the front of the chain, choosing who gets exploited at all, rather than at the back forcing an outcome.

01
Reconnaissance

Narrow the target to an address range

T1590.005Gather Victim Network Information: IP Addresses — restricts watering-hole delivery to specific IP ranges, so only the intended organisations are ever served an exploit.
T1592.002Gather Victim Host Information: Software — script on the compromised site profiles browser type, system language and Flash Player version before anything is delivered.
knowing exactly who and what they face, they assemble the toolkit
02
Resource Development

Build on commodity tooling

T1588.001Obtain Capabilities: Malware — adopts publicly available remote access trojans rather than writing bespoke implants, which keeps the operation cheap and the attribution noisy.
with RATs in hand, they set two different traps
03
Initial Access

Poison the sites the target already trusts

T1189Drive-by Compromise — watering-hole attacks on legitimate South Korean sites, frequently carrying zero-day exploits and gated to the IP ranges profiled in phase 01.
T1566.001Phishing: Spearphishing Attachment — parallel campaigns delivering malicious Word and Excel attachments.
each route needs something to actually run the code
04
Execution

Exploit the browser, or persuade the user

T1203Exploitation for Client Execution — chains numerous ActiveX vulnerabilities, including zero-days, against visitors to the poisoned sites.
T1204.002User Execution: Malicious File — where no exploit is available, lures the recipient into enabling macros in the attachment instead.
a first-stage foothold is only useful if more tooling can follow it
05
Command and Control

Pull down the rest of the toolkit

T1105Ingress Tool Transfer — stages additional tools and malware onto the compromised host, including gh0st RAT and Rifdoor.
those payloads have to cross the wire without being recognised
06
Stealth

Hide the executable inside a picture

T1027.003Obfuscated Files or Information: Steganography — embeds malicious executables inside PNG files, so the payload traverses the network as an ordinary image download.
established quietly on the host, they survey it
07
Discovery

Survey the host with built-in utilities

T1057Process Discovery — runs tasklist to enumerate running processes and search for a specific string.
T1049System Network Connections Discovery — runs netstat -naop tcp to enumerate active TCP connections.
the survey tells them which files are worth taking
08
Collection

Stage files for extraction

T1005Data from Local System — gathers large numbers of files from compromised systems and holds them for later extraction.
those staged files are what the whole operation was for
09
The Objective — reported, not mapped

Intelligence out, quietly

This phase carries no ATT&CK technique ID, because the G0138 mapping contains none. MITRE's technique list for Andariel stops at Collection — there is no Exfiltration or Impact technique attributed to the group. The objective below is drawn from the group's documented purpose and from the wording of T1005 itself, which describes files gathered "for later extraction".

Andariel operates for the Reconnaissance General Bureau against South Korean government, military, financial and defence targets, in campaigns including Operation Black Mine, Operation GoldenAxe and Campaign Rifle. The objective is intelligence and revenue for the state — not disruption, which is why nothing in this flow breaks anything.

The Arsenal

Two named implants, both commodity

A deliberately small arsenal. Andariel's investment goes into target selection and delivery, not into implant development — which is exactly what T1588.001 above describes.

Source: MITRE ATT&CK — Andariel (G0138). Technique mappings reflect publicly reported Andariel activity; tooling names are indicators of compromise, shown for analyst reference.

Coverage caveat — read before using this for gap analysis. The G0138 mapping is sparse. It attributes no techniques to Persistence, Privilege Escalation, Credential Access, Lateral Movement, Exfiltration or Impact. Absence here means absence from the published mapping, not evidence that Andariel lacks those capabilities — a group active since 2009 that stages files "for later extraction" plainly exfiltrates them. Treat the empty tactics as collection gaps in the reporting, not as defensive assurance.
