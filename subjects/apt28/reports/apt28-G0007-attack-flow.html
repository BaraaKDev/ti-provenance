Attack Flow G0007

APT28.

An intrusion that increasingly starts on equipment you do not own. The first two phases below happen on rented servers and other people's routers, before anything touches the target — and the last phase takes mail rather than money.

The Intrusion

Two phases before they touch you, and none of it is malware

Ordered as the operation runs rather than as the matrix lists — escalation is shown before persistence because the launcher has to reach SYSTEM before the scheduled task it installs is worth anything. Eight tactics carry no techniques and are named in the footer rather than filled in.

01
Resource Development

Build a DNS service out of rented servers and other people's routers

T1583.003 Acquire Infrastructure: Virtual Private Server — configures rented servers as malicious DNS resolvers. Two clusters are identifiable by their banners: SSH on TCP 56777 or 35681, with dnsmasq 2.85 answering on UDP 53.
T1584.008 Compromise Infrastructure: Network Devices — takes over SOHO routers, principally TP-Link models including the WR841N, Archer C5 and C7, and rewrites their DHCP-supplied DNS settings to point at those resolvers. MikroTik devices in Ukraine are handled by hand rather than at scale.
Infrastructure that answers DNS is only useful once something is pointed at it, or once a message lands in a mailbox.
02
Initial Access

Two doors: the router's web page, and the inbox

T1190 Exploit Public-Facing Application — against the router's own web interface, likely through CVE-2023-50224 on the WR841N. One crafted HTTP GET retrieves stored credentials, a second rewrites the DNS settings. The original resolver is demoted to secondary rather than removed, so name resolution keeps working and nothing appears broken.
T1566 Phishing — carries two different operations: cross-site scripting payloads that run inside the victim's webmail session, and crafted messages that make Outlook authenticate outbound. Sent from co-opted public mail services rather than actor-registered domains, so sender reputation gives nothing away.
A foothold on a Windows host is worth nothing at user privilege, so the first thing to run is the thing that climbs.
03
Execution

Let a batch file do the work the implant would be caught doing

T1059.003 Command and Scripting Interpreter: Windows Command Shell — GooseEgg spawns elevated processes and drives them from batch scripts named execute.bat and doit.bat. The launcher itself does very little, which is what keeps it small and unremarkable.
Those scripts need SYSTEM before they can touch a registry hive or install a task that survives.
04
Privilege Escalation

A print spooler bug, held quietly for four years

T1068 Exploitation for Privilege Escalation — GooseEgg exploits CVE-2022-38028 in the Windows Print Spooler by modifying a JavaScript constraints file and executing it with SYSTEM permissions. In use since at least June 2020 and possibly April 2019, which is years before the flaw was publicly fixed.
With SYSTEM in hand, the next move is to make sure the access outlives both the reboot and the password reset.
05
Persistence

One task on the host, one permission on the mailbox

T1053.005 Scheduled Task/Job: Scheduled Task — installed through the same batch scripts, so the launcher returns after reboot rather than depending on the original foothold staying open.
T1098.002 Account Manipulation: Additional Email Delegate Permissions — alters Exchange mailbox permissions so mailboxes of interest can be read without authenticating as their owner. Named in the ten-nation advisory as both a way in and a way to stay.
Access to one estate is a foothold; access to its credentials is a key to the next one.
06
Credential Access

Five ways to take an identity, and only one involves malware

T1110.003 Brute Force: Password Spraying — guessed credentials across many accounts, named as a primary route into logistics and technology organisations. The joint advisory leads its mitigations with phishing-resistant multi-factor authentication for exactly this reason.
T1187 Forced Authentication — CVE-2023-23397 makes Outlook authenticate to an attacker-controlled server with no user interaction. The NTLMv2 hash is captured and relayed. Used as a zero-day from 18 March 2022 and in two further waves after the patch, against at least 30 organisations in 14 nations. Compromised Ubiquiti devices collect the messages.
T1557 Adversary-in-the-Middle — once a hijacked router resolves a login domain to actor infrastructure, the operator sits in the connection and harvests passwords and OAuth tokens from browsers and desktop clients alike. Lookups outside the targeting criteria resolve normally, so nothing about the network feels wrong.
T1111 Multi-Factor Authentication Interception — SpyPress.MDAEMON steals two-factor secrets from the webmail session and creates application passwords, which are honoured without a second factor and therefore outlive the victim's MFA entirely.
T1003.002 OS Credential Dumping: Security Account Manager — registry hives extracted after GooseEgg reaches SYSTEM, by the same scripts that installed the scheduled task.
Everything above exists to reach one thing, and it is not the network.
07
Collection — the objective

Take the mail, then arrange to keep receiving it

T1114 Email Collection — credentials stolen and mail and contacts exfiltrated through JavaScript injected into the victim's own webmail page. Against Roundcube first, later Horde, MDaemon and Zimbra, targeting Ukrainian government bodies and Eastern European defence companies. SpyPress.ROUNDCUBE, SpyPress.MDAEMON.
T1114.003 Email Collection: Email Forwarding Rule — Sieve rules installed in the mailbox forward incoming mail onward automatically. This is the part that survives a password reset, because the rule belongs to the mailbox and not to the session that created it.

The Arsenal

A twenty-year toolset, and the newest parts are the smallest

The old names — X-Agent, Zebrocy, Drovorub — are full implants from an era when the objective was a host. The recent additions are a privilege-escalation launcher and two lumps of JavaScript that live in a webmail page, because the objective is now the mailbox and there is no reason to put a binary on disk to reach it.

Read the ordering correctly. The phases run in the order the operation runs, not the order the matrix lists. Privilege Escalation appears before Persistence because the launcher must hold SYSTEM before the scheduled task it installs is worth anything, and the registry hives it reads are unreadable without it.

Derived mapping — read before citing. MITRE publishes a G0007 entry, but the techniques on this page were derived by analysis from the cited reporting rather than copied from it, so they will not match that entry row for row. Every technique ID and tactic assignment was verified against attack.mitre.org before use; applying each one to this actor remains an analytical judgment. Two placements are worth flagging: the Outlook flaw is mapped to Credential Access rather than Initial Access because what it yields is an NTLM hash, and the router work sits in Resource Development because those devices are infrastructure for the operation rather than the target of it.

Coverage gaps. Eight Enterprise tactics carry no techniques here — Reconnaissance, Stealth, Defense Impairment, Discovery, Lateral Movement, Command and Control, Exfiltration and Impact. That reflects what the cited sources describe, not the limit of this actor's capability: a group operating for twenty years plainly moves laterally and exfiltrates, but the reporting reviewed here does not describe how, and inventing the steps would produce a more complete-looking page that asserts things nobody has observed.

Attribution. The link to GRU unit 26165 is a published government assessment, carried by the UK NCSC at "almost certainly" and stated jointly by the US and UK governments. The webmail activity is attributed by ESET at medium confidence, and is the one part of this page resting on a single vendor.
